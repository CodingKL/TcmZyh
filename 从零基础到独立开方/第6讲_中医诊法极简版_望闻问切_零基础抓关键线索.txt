自学中医完整体系课·第6讲 中医诊法极简版：望闻问切，零基础抓关键线索

（本草笺方录｜60讲体系课更新）
 
前面我们把脏腑、经络、气血、阴阳都讲明白了。
从这一讲开始，进入真正看病的实操环节——中医诊法：望、闻、问、切。
 
很多自学的人一上来就想学切脉，其实完全没必要。
零基础最实用的顺序是：
一问、二望、三闻、四切
抓住关键线索，就能辨证八九不离十。

 
一、问诊：问出80%的病机
 
问诊是最简单、最准确、最容易上手的诊法。
你只要问清楚 7 件事，病机基本就定了。
 
1. 问寒热：辨阴阳、表里
怕冷、怕风、添衣就缓 → 寒、表证、阳虚
怕热、烦躁、想喝凉水 → 热、里证、阴虚
 
2. 问汗：辨虚实、表里
无汗 → 表实、寒闭
自汗、一动就出汗 → 气虚、阳虚
夜里盗汗、醒了就停 → 阴虚
 
3. 问疼痛：辨虚实、寒热、经络
胀痛、生气加重 → 气滞（多在肝）
刺痛、固定不移 → 血瘀
冷痛、热敷舒服 → 寒
灼痛、遇凉减轻 → 热
隐隐痛、按了舒服 → 虚
剧痛、拒按 → 实

4. 问睡眠：辨心、肝、胃
入睡难、心烦、多梦 → 心火、肝火
易醒、心慌、健忘 → 心脾两虚
睡不沉、梦多、潮热 → 心肾不交、阴虚
胃胀、嗳气、睡不安 → 胃不和则卧不安
 
5. 问二便：辨脾、肾、寒热、湿
大便稀、不成形、吃凉就拉 → 脾虚、寒
大便干结、口臭 → 胃热、肠燥
大便粘马桶、冲不干净 → 湿气、湿热
小便清长、夜尿多 → 阳虚、肾虚
小便短黄、灼热 → 热证
 
6. 问饮食口味：辨脾胃、寒热
吃不下、胃胀 → 脾虚、气滞
容易饿、吃得多 → 胃热
口淡、不渴 → 寒、虚
口苦 → 肝胆火旺、少阳病
口甜、口黏 → 脾胃湿热
口酸 → 肝胃不和
 
7. 问妇女经带：辨肝、脾、肾、寒、瘀 
月经提前、量多、色鲜 → 热、气虚不固
月经推后、量少、色暗 → 寒、血虚、瘀
痛经冷痛、热敷缓解 → 宫寒
痛经胀痛、生气加重 → 气滞
血块多、刺痛 → 血瘀
白带清稀、量多 → 寒、虚
白带黄稠、异味 → 湿热
 
 
二、望诊：一眼看状态
 
零基础不用复杂，只看 4 点就够。
 
1. 望神 
精神好、眼神亮 → 正气足
萎靡、懒言、无神 → 气虚、阳虚、病重
 
2. 望面色 
面色淡白、萎黄 → 血虚、气虚
面色红 → 热、上火
面色暗、青、黑 → 寒、瘀、肾虚
面色油腻、长痘 → 湿热、痰湿
 
3. 望舌（最关键）
舌淡白 → 寒、虚、血虚
舌红 → 热
舌胖大、有齿痕 → 气虚、脾虚、湿
舌暗、有瘀点 → 血瘀
苔白 → 寒、湿
苔黄 → 热
苔厚腻 → 痰湿、湿热
 
4. 望形态
胖而乏力、肉松 → 气虚、痰湿
瘦而口干、心烦 → 阴虚
弯腰驼背、畏冷 → 阳虚



三、闻诊：听声音、嗅气味
 
简单两招，立刻能用。
 
1. 听声音
声音洪亮、说话快 → 实、热
声音低弱、懒得说话 → 气虚、阳虚
咳嗽声重、痰白 → 寒
咳嗽洪亮、痰黄 → 热
嗳气、叹气多 → 气滞、肝胃不和
 
2. 嗅气味
口气重、口臭 → 胃热、积食
大便臭、屁臭重 → 食积、湿热
白带黄稠异味 → 湿热
 
 
 
四、切诊：脉诊极简入门
零基础不用背几十种脉，只抓 4 个纲领。
 
1. 浮脉 
轻按就摸到 → 病在表（感冒、外感）
 
2. 沉脉 
重按才摸到 → 病在里（脏腑、慢性病）
 
3. 迟脉 
跳得慢 → 寒证
 
4. 数脉 
跳得快 → 热证
 
再加两个常用：
 
虚脉、无力 → 气虚、血虚
滑脉、如滚珠 → 痰湿、食积、怀孕
 
对你来说：问诊+舌诊 ＞ 脉诊。
先把前两个练熟，已经超过很多爱好者。
 
  
五、零基础诊病万能流程
 
1. 问主诉：最难受的是什么
2. 问寒热、汗、睡眠、二便、饮食
3. 看面色、看舌象
4. 听声音、看精神
5. 简单摸脉（浮沉、快慢、有力无力）
6. 得出：表里、寒热、虚实、脏腑病机
 
 
 
本讲总结
 
问诊定方向，问 7 点就够
望诊看关键：神、色、舌、形
闻诊听声辨寒热虚实
切诊抓四大纲领脉
四诊合参，不靠单一信息判断
 
 
 
第6讲作业（极简练习）
 
给自己或家人做一次极简问诊：
 
1. 怕冷还是怕热？
2. 睡眠怎么样？
3. 大便正常吗？
4. 舌象大概是什么样？
试着总结一句病机。
