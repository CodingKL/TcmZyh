自学中医完整体系课·第3讲 气血津液精：人为什么会虚、会堵、会寒

（本草笺方录｜60讲体系课更新） 

上一讲我们把阴阳五行翻译成了临床大白话，很多朋友反馈一下子就通了。
今天这一讲，是中医零基础最实用的一课——气血津液精。 

你平时听到的虚、累、冷、堵、胖、肿、痛、失眠、月经不调……几乎所有问题，根源都在这四个东西上。
这一篇让你一听就懂、一对照就知道自己是哪一种问题。  


人体的生命活动，全靠四种物质支撑：气、血、津、液、精
我把它们简化成最容易理解的三个部分：气、血、津液精，一次性讲透。 

一、气 → 身体的「能量与动力」⚡ 
气，就是人体的能量、动力、温度、防御系统。
气不足、气不走，人就虚、冷、累、堵。 

气的4个核心作用 

推动：让血动、让消化动、让月经来、让大便通
温煦：给身体供暖，手脚暖不暖全靠气
防御：抵抗感冒、外邪，少生病
固摄：兜住血、汗、大小便、月经、白带 

气出问题，只有两种情况 

1. 气虚——能量不足
表现：浑身没劲、懒得说话、一动就累、容易感冒、出汗多、大便不成形、月经拖尾、脏器下垂
一句话：干啥都没力气
2. 气滞——能量堵了
表现：胸闷、胃胀、叹气、乳房胀痛、痛经胀痛、生气就加重、肚子里咕噜响
一句话：到处胀、堵得慌 

气虚要补，气滞要疏，方向完全相反，这是最基础的判断。  

二、血 → 身体的「营养与滋润」🩸 
血，负责营养全身、滋润脏腑、养心神、管月经。
血不足、血不走，人就干、晕、弱、痛、失眠。 

血出问题，也是两种情况 
1. 血虚——营养不够
表现：脸色苍白/发黄、头晕眼花、心慌、失眠多梦、手脚麻、月经量少、眼睛干、指甲脆
一句话：干、弱、晕、睡不好

2. 血瘀——血堵住了
表现：刺痛、固定痛、夜里加重、月经有血块、脸色暗、长斑、舌下青筋粗
一句话：痛得厉害、有血块、颜色暗 

血虚要补，血瘀要通，千万不能搞反。  

三、津液精 → 身体的「水分与肾精」💧 
津液负责滋润、代谢水湿；精是先天之本，管生长、生殖、免疫力。 
津液问题：最常见就是「湿」 

湿气重
表现：身体沉重、睡不醒、大便粘马桶、肚子大、痰多、皮肤油、浮肿
一句话：困、重、粘、肿 

水饮
表现：心慌、头晕、吐清水、肚子里有水声、浮肿
比湿气更重一层。 

精不足：就是肾虚核心 

表现：腰膝酸软、脱发耳鸣、记忆力下降、月经不调、不孕、夜尿多、怕冷或潮热
这是人体的“底子”问题。  

四、人为什么会虚、堵、寒、湿❓ 

所有常见病，都逃不出这几个组合： 

气虚 → 怕冷、乏力、易感冒
气滞 → 胀痛、生气加重、失眠
血虚 → 头晕、心慌、月经量少
血瘀 → 刺痛、血块、长斑
湿气 → 沉重、粘马桶、胖
肾虚 → 腰酸、脱发、夜尿多 

最常见的临床组合（对照） 

气虚+阳虚 = 怕冷、乏力、腹泻（虚寒体质）
气滞+血瘀 = 痛经、胀痛、胸闷（气郁血瘀）
脾虚+湿气 = 困重、大肚子、大便粘（痰湿体质）
血虚+阴虚 = 失眠、口干、手脚心热（虚热体质） 

你只要能分清：是虚还是堵，是寒还是湿，中医辨证你已经入门了。 

五、最简单的自我判断法✨ 

不问复杂理论，只看3点： 

1. 累不累、冷不冷 → 气虚、阳虚
2. 胀不胀、痛不刺痛 → 气滞、血瘀
3. 重不重、粘不粘 → 湿气、痰湿 

90%的人，都能靠这三句找到自己的体质根源。  

本讲总结💡 
气是动力，虚了就累，堵了就胀。
血是营养，少了就晕，堵了就痛。
津液是水分，多了就湿，少了就干。
精是底子，亏了就虚，弱了就累。 

人所有的不舒服，本质就是：
气不足、气不走、血不够、血不通、水湿重、肾精亏。 

把这一课吃透，你看自己、看家人，一眼就能看出问题在哪。   

第3讲作业 
观察自己或家人，回答三句话： 
1. 是偏虚，还是偏堵？
2. 是偏寒，还是偏湿？
3. 主要问题在气、在血，还是在湿气？ 

不用开方，只练病机判断。
