自学中医完整体系课·第4讲   脏腑功能精讲：心、肝、脾、肺、肾，核心病机一句话总结

（本草笺方录｜60讲体系课更新） 

前面三讲，我们把中医思维、阴阳五行、气血津液都打通了。
从这一讲开始，正式进入脏腑辨证，这是你以后看病、开方最常用的核心工具。

我不讲课本长文，每脏只给你三句话：
功能是什么？
有病会怎样？
病机怎么总结？
零基础，听完就能直接用。 

一、心 ：主管神明、血脉 
心，管两件大事：睡得好不好、血脉通不通。

心的核心功能
主血脉：全身血液运行、心跳、面色
主神明：睡眠、情绪、记忆力、神志 

心出问题的常见表现
心慌心悸、胸闷气短
失眠多梦、易醒、睡不着
健忘、心烦、焦虑
面色苍白或发红、舌尖红赤 

一句话抓心病机
睡不着、心烦、舌尖红 → 心火亢盛
心慌、乏力、面色淡 → 心气血不足
胸闷、心痛、舌暗 → 心血瘀阻
心慌、头晕、健忘 → 心脾两虚 


二、肝 ：主管疏泄、藏血 
肝是人体“总指挥”，管情绪、月经、眼睛、疏通全身。 

肝的核心功能
主疏泄：情绪、气机、消化
主藏血：调节血量、月经、眼睛 

肝出问题的常见表现
爱生气、胸闷、爱叹气
乳房胀痛、痛经、月经不调
头晕、头胀、眼睛干、眼睛红
胃胀、反酸、口苦（肝犯脾胃） 

一句话抓肝病机
生气就胀、胸闷 → 肝气郁结
头晕头胀、眼红 → 肝火上炎
眼干、月经量少 → 肝血不足
生气就胃疼、腹泻 → 肝木克脾土


三、脾 ：主管运化、气血生化之源 
脾是后天之本，管吃饭、消化、力气、湿气、肌肉。 

脾的核心功能
主运化：消化食物、吸收水湿
主气血生化：人有没有力气全看脾
主升清、主统血：稳住月经、内脏不下垂

脾出问题的常见表现
胃胀、吃一点就饱
大便稀溏、不成形、粘马桶
乏力、懒动、面色发黄
浮肿、痰多、肚子大（湿气重） 

一句话抓脾病机
乏力、大便稀 → 脾气虚
怕冷、腹泻 → 脾阳虚
身体重、大便粘 → 脾虚湿盛
出血、月经拖尾 → 脾不统血 


四、肺 ：主管呼吸、皮毛、防御 
肺是人体第一道防线，管呼吸、感冒、皮肤、排痰。 

肺的核心功能
主气司呼吸：喘气、咳嗽
主宣发肃降：排汗、排痰、通肠道
主皮毛：皮肤、毛孔、抵抗力 


肺出问题的常见表现
感冒、怕冷、易出汗
咳嗽、痰多、嗓子痒
气短、说话没力气
皮肤干、易过敏


一句话抓肺病机
怕冷、流清涕、咳嗽 → 风寒犯肺
嗓子痛、黄痰 → 风热犯肺
咳嗽、白痰、胸闷 → 痰湿阻肺
气短、易感冒 → 肺气虚 

五、肾 ：主管先天、生殖、水液
肾是先天之本，管腰、腿、头发、月经、生育、衰老。 

肾的核心功能
藏精：生长、发育、生殖
主水：小便、浮肿
主骨生髓：腰、腿、牙齿、记忆力


肾出问题的常见表现
腰膝酸软、腰痛
脱发、耳鸣、记忆力下降
夜尿多、小便清长
月经不调、不孕、怕冷或潮热 


一句话抓肾病机
腰膝酸、乏力 → 肾气虚
怕冷、夜尿多 → 肾阳虚
潮热、盗汗、口干 → 肾阴虚
头晕、腰膝酸软、月经少 → 肝肾阴虚 


零基础快速定位脏腑口诀 
一看睡眠情绪 → 找心、肝
二看吃饭大便 → 找脾
三看咳嗽感冒 → 找肺
四看腰腿月经 → 找肾 

所有复杂症状，都可以用这5句快速锁定病位。 

本讲总结  
心：管睡眠、血脉，慌、烦、睡不着多在心
肝：管情绪、月经，胀、痛、生气多在肝
脾：管消化、湿气，累、泻、胖多在脾
肺：管呼吸、防御，咳、痰、感冒多在肺
肾：管腰、生殖，酸、虚、早衰多在肾

把这五脏病机背熟，你已经具备独立辨证的基础框架。 

第4讲作业（极简练习） 
看自己或家人一个症状，回答： 
1. 病位在心、肝、脾、肺、肾哪一个？
2. 是虚、实、寒、热、湿里的哪一种？
