Stripe Link（官方常称为 Link by Stripe 或 Link）是 Stripe 推出的一款数字钱包与一键加速结账工具。
用户只需保存一次支付和配送信息，就能在所有支持 Link 的商家或网站上自动填充并快速完成付款。

核心功能与特点

• 一键快速结账：通过邮箱、手机号或 Cookie 识别用户，自动填充银行卡、账单和收货地址，结账速度更快。
• 多元支付方式：除银行卡外，还支持即时银行支付、先买后付（如 Klarna）、部分地区支付方式（如 Pix、UPI）以及稳定币等。
• 安全验证：具备 PCI 1 级安全认证，在新设备或浏览器上使用时通常会通过短信或一次性验证码进行身份验证。
• 商家集成与扩展：可内置于 Stripe Checkout、Payment Links、Payment Element 等结账界面，也支持 AI 智能体支付等场景。

常见使用场景与相关概念

• 消费者购物与订阅：在电商独立站或 SaaS/AI 服务（如订阅计划）结账时，勾选或使用 Link 一键付款，无需每次手动输入卡号。
• 商家提升转化：商家启用 Link by Stripe 后，无需单独对接每种支付方式即可为买家提供更顺畅的结账体验。
• 注意区分“收款链接”：部分用户会把 Link 和 Stripe 的 Payment Links（付款链接） 混淆——前者是“数字钱包/加速结账”，后者是商家无需写代码即可生成的“收款网页链接”。更多细节可查阅 Link 常见问题解答。
